The first release of **Wandro — the map collection game**: the project foundation, the backend
and a playable app preview for the Sintra pilot (roadmap Phases 0–2).

**Try it:** run `pnpm install && pnpm web`, or open the hosted web demo linked in the repository's
About section. The app runs in demo mode with sample Sintra places and progress saved on your
device.

## Highlights

- **Fog-of-war map of Sintra.** Places start locked under fog. Discovering one clears the fog in an
  animated circle. Category filters, a legend and a Google Maps-style place sheet with points,
  rarity, distance and directions.
- **Gamified onboarding.** A "hold to clear the fog" entry portal and registration where you pick
  your explorer style.
- **Instagram-style home.** A progress strip (level, octopus stage, points), places near you and
  your discoveries.
- **Discovery flow.** "You're at X", hold to start, a dwell ring, then points. Demo mode includes
  "Teleport here" so it can be tried from anywhere.
- **Daily challenge, touch to confirm.** A rolling 24-hour challenge. After a matching discovery,
  press and hold to claim +75. The server re-checks everything and pays out once.
- **Approved missions.** Players suggest places with a safety checklist, and moderators approve
  them into live places on the map.
- **Profile and collections.** A "map of you", stats, badges and collection progress.

## Under the hood

- pnpm monorepo with strict TypeScript, ESLint, Prettier and GitHub Actions CI.
- Supabase schema with PostGIS: profiles, places, visits, an append-only points ledger, daily
  challenges and place submissions.
- Row-level security: the app can never write points, visits or rarity. Private property can
  never be an active challenge.
- A shared scoring package for the rarity multiplier, first-discoverer bonus, levels and fog
  geometry.
- An idempotent OpenStreetMap and Wikidata importer for the Sintra bounding box, with safety
  filters and de-duplication.
- Maps use Mapbox on phones, MapLibre with OpenStreetMap on the web, and a schematic fallback in
  Expo Go.
- Tests: 37 unit and component tests and 30 database tests, all passing in CI.
- Web app deployment to GitHub Pages and automated releases.

## Known limitations

- Verified server check-ins arrive in v2.0 (Phase 3). With a real backend, places can't be
  discovered yet. The full flow works in demo mode.
- The native Mapbox map, Google and Apple sign-in, and the live place import need accounts and keys
  and haven't been verified on devices yet.
- Place photos and some coordinates in the demo data are placeholders.
